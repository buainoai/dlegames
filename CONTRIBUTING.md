# Contributing to DLE Games

Thanks for helping players discover useful daily games.

## Submit a game

Open the **Submit a game** issue template after this repository is published. Include:

1. The game's official name and playable URL
2. A factual one- or two-sentence description in English
3. How the puzzle is played and whether it resets daily
4. The best-fit category (word, geography, logic, music, movies, sports, trivia, or other)
5. Whether it works on mobile and requires a login or payment

Only submit games whose links you have checked. Do not submit affiliate redirects, copied/cloned games presented as official, malware, or pages that do not actually host the described game.

## Editorial guidelines

- Prefer the **official playable game URL** over third-party mirrors.
- Describe the actual mechanic, not marketing superlatives.
- Clearly identify unlimited versus once-a-day play.
- Avoid promises like “100% free” when only a trial is free.
- Don't copy another site's long descriptions or copyrighted reviews.
- Report outdated entries, redirects, and broken games.

## Issue discussion

Use a separate issue for each game so changes can be reviewed independently. Do not disclose private credentials, email addresses, or user data in public issues.

## Contribution and publishing expectations

Submitting an issue does not automatically add a game to dlegames.org. The site owners review submissions editorially and update the production directory separately.

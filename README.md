# DLE Games — Discover Daily Games Like Wordle

**[DLE Games](https://dlegames.org/)** is a curated directory for daily browser games, puzzles, Wordle alternatives, and quick guessing challenges.

Players can discover word games, geography challenges, music quizzes, movie trivia, sports games, logic puzzles, and more. Most listed games can be played in a web browser without installing anything.

🌐 **Official website:** [dlegames.org](https://dlegames.org/)

## What makes a useful daily game directory?

- A clear explanation of how each game works
- Direct links to the official place to play
- Useful categorization by theme and puzzle mechanic
- Search and discovery beyond the most famous Wordle clones
- Regular checks for broken, moved, or discontinued games

## Suggest a game

Have a daily puzzle or browser game that is missing from the directory?

Use this repository's **Submit a game** issue template to suggest a listing. For website questions, you can also use the [DLE Games contact page](https://dlegames.org/contact-us).

See [CONTRIBUTING.md](CONTRIBUTING.md) for the editorial criteria and [docs/game-entry-format.md](docs/game-entry-format.md) for a proposed structured data format.

## Scope of this repository

This is the **public project and community hub**, not the production codebase of dlegames.org. Repository files contain docs, examples, and community issue templates. They do not expose private infrastructure, analytics, paid services, or production credentials.
